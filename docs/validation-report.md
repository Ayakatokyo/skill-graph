## 真实浏览器操作

Codex 内置浏览器，实际运行生产静态资源；示例来自本机 Skill Creator 的 11 个节点、12 条连线及 45 处来源定位。

1. 核对来源，显示一致；选择节点能查看文件、行号、章节与摘录。
2. 拖动“检查技能结构”，布局变化，流程改动仍为 0。
3. 修改该节点职责并添加修改批注，记录 1 项净差异及 1 条原话批注。
4. 删除该节点后保留批注并提示对象已移除；撤销恢复节点、连线和批注。
5. 修改连线条件并添加问题批注，提示词将问题独立放入“不构成修改要求”分区。
6. 新增步骤、从现有节点的输出圆点拖向新步骤的输入圆点，形成第 13 条连线；撤销后回到预期的 2 项差异、2 条批注。
7. 切换“分析现状”，原始职责字段只读；刷新后恢复草稿。
8. 复制完整会话，检查全部来源和批注；将其保存后通过文件选择器重新导入，再复制。前后完整 JSON 摘要一致：`847fb6a91f9534d504fd52639d879688f8c9f0fc3656198197241cd88dfb6ac4`。
9. 最终构建提示词明确把期望行为标为“拟修改，尚未实现”；浏览器未报告控制台错误。
10. 最终演示切至 ZIP 解压版的 4318 端口，使用干净示例，显示 0 项流程改动、0 条批注与来源核对通过。
