# Skill Graph

Product tool for a developer understanding and improving one local Skill. Used on a desktop in daylight while comparing complex instructions and branches. The interface is a working canvas, not a marketing page. Keep the existing approved design in docs/skill-graph-design.md authoritative.

Use a readable light neutral canvas, white panels, deep green accent, precise Chinese labels, visible keyboard focus, reduced-motion support, and source evidence accessible from selected steps. Preserve the user's work through save, reload and undo. Distinguish current behavior from proposed edits.
